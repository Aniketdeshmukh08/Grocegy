Grocerz – Online Grocery Shopping Application

Grocerz is an online grocery shopping web application designed to make grocery browsing and purchasing convenient for customers. The project includes product browsing, category management, and shopping-related functionality to provide a user-friendly shopping experience.

Key Features

Product listing and browsing

Product categories and subcategories

Shopping cart and checkout functionality

Customer management

Order management

Product and category image management

REST API integration

Database integration for storing and managing application data

Technologies

Frontend: JavaScript and web technologies

Backend: Node.js and Express.js

Database: SQL/MySQL or the database configured in the project

Tools: Git, GitHub, and Postman
